# lessons-learned

Post-task iterative improvement capture — observes friction points, proposes fixes, implements them, and records patterns to memory.

## What it does

After completing any non-trivial task, this skill provides a structured workflow to:

1. Observe friction points, drift, and missing features during execution
2. Summarize observations with categories (Performance, UX, Drift, Bug, etc.)
3. Ask whether to fix issues immediately
4. Implement approved fixes across all affected files
5. Commit with context tying fixes back to observations
6. Update persistent memory for recurring patterns

## Skills

- `lessons-learned` — Main observation and improvement workflow
