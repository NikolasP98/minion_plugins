# mintlify

Mintlify documentation platform expert — guides creating and maintaining docs sites with MDX, navigation config, API docs, and deployment.

## What it does

Provides expert guidance for Mintlify documentation projects:

- Understand project structure via `docs.json`
- Write content following Mintlify conventions (MDX, components, frontmatter)
- Configure navigation (tabs, groups, anchors, dropdowns)
- Set up API documentation from OpenAPI specs
- Follow writing standards (voice, formatting, component usage)
- Deploy and configure redirects/SEO
